# The Pixel Patch

The Pixel Patch is a web game hub consisting of the following games:
- Rock, Paper, Scissors
- Tic Tac Toe (with Multiplayer)
- Wordle
- Hangman

## Setup
1. Install dependencies
```
npm install
```
2. Run project with: 
```
npm run dev
```

## Deployment
Deployment is automatic: pushing to `main` triggers a Vercel deploy.

## Access
Access the live site at https://the-pixel-patch.vercel.app/
